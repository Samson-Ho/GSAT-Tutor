# GSAT-Tutor privacy

Effective date: 2026-10-07. Publisher: Samson Ho.

GSAT-Tutor is a skills-only tutoring package: instructions, references, exam
PDFs, and an optional local vocabulary helper. It operates no backend, requires
no separate account or OAuth connection, requests no API keys or passwords,
and independently collects no telemetry or prompt history. The package does
not send student work to a GSAT-Tutor service or independently retain it.

The assistant uses the questions, answers, essays, and learning context you
choose to provide in the host conversation to explain concepts and give
feedback. Names, contact details, school identifiers, or other identifying
information are unnecessary; remove them from work you share. There is no
GSAT-Tutor database, recipient list, retention period, or separate deletion
control for conversations. Conversation storage, tools, sharing, and deletion
remain governed by your host platform's own privacy policy, terms, and
available controls. This document makes no claim about OpenAI, Anthropic,
Apple, or another platform's retention practices.

The optional vocabulary script reads the bundled vocabulary reference and
text you explicitly supply through a file or standard input. It prints the
result locally, makes no network requests, and stores no separate profile.
Shell history and output retention depend on the environment you run it in.

Support is available through [GitHub Issues](https://github.com/Samson-Ho/GSAT-Tutor/issues).
If you open an issue, the information you post is handled by GitHub and may be
public. Share a minimal, anonymized example; do not post private student work,
credentials, or identifying information. To change or delete an issue, use
GitHub's controls. Host-account privacy requests should use that host's
support channel.
