# GSAT-Tutor support

Report installation problems, missing resources, or incorrect explanations at
[GitHub Issues](https://github.com/Samson-Ho/GSAT-Tutor/issues).
Include the plugin version, subject, host app, steps to reproduce, and a small
anonymized example. Issues are public: remove personal information and do not
post private student work or credentials. No response-time guarantee is made.

For billing, host accounts, directory access, or installation restrictions
managed by your organization, contact the host platform or administrator.
Tutor scores are estimates for learning, not official examination results.
