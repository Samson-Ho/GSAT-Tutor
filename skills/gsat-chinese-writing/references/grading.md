# 國寫 — Grading Essays, Writing 評分原則, Diagnosing Weaknesses

Grade the way the 大考中心 閱卷委員 do: decide the **等** first, then the **級**, then the **分數**. Anchor every judgment in the general standard (表現描述) and in the task-specific rubric.

## 1. The general scoring standard

### 1.1 Procedure (考試說明 p35; 115 評分原則說明, verbatim)
> 閱卷委員評閱各題時，先判定「等」，再決定「級」，最後擇定「分數」。

> 每份試卷閱卷委員在評分過程中，會先分 A、B、C 三等，進而在該等中，依表現高下判斷屬於原級或＋級，再從所認定的級別內選取最適當的分數。此一評分方式，既能透過等級的判定達成共識，又能依據個別情形（如內容恰當與否、錯別字多寡、標點符號正確與否等）選擇較適確的分數。

### 1.2 三等六級 scales

| 等 | 級 | 25分題 | 21分 問題（二） | 18分 問題（二） | 4分 問題（一） | 7分 問題（一） |
|---|---|---|---|---|---|---|
| A | A＋ | 25–22 | 21–19 | 18–16 | A 4–3 | 7 |
| A | A | 21–18 | 18–15 | 15–13 | ↑ | 6 |
| B | B＋ | 17–14 | 14–12 | 12–10 | B 2 | 5 |
| B | B | 13–10 | 11–8 | 9–7 | ↑ | 4 |
| C | C＋ | 9–6 | 7–5 | 6–4 | C 1 | 3 |
| C | C | 5–1 | 4–1 | 3–1 | ↑ | 2–1 |
| 0 | 0 | 0 | 0 | 0 | 0 | 0 |

- 25 and 21: official (考試說明 p36; 111–115 評分原則). 4: official since 111.
- 18 and 7: the 7+18 情意 tasks in the 參考試卷 (卷二 金盒子, p29–31) print these bands (7分: A+ 7, B+ 5, C+ 3, C 2–1, with A 6 and B 4 between them).
- The 4分 問題（一） uses only three 等 (A 4–3, B 2, C 1), with no ＋級.

### 1.3 What each 等 means: the 表現描述 (考試說明 p56, verbatim)

| 等 | 知性的統整判斷 (第一大題) | 情意的感受抒發 (第二大題) |
|---|---|---|
| A | 能精確掌握題旨，善用各種材料加以拓展發揮，思考深刻，論述明確，結構嚴謹，文辭暢達。 | 能精確掌握題旨，發揮想像，構思巧妙，體悟深刻，結構完整，情辭動人。 |
| B | 大致能掌握題旨，取用相關材料加以論述，內容平實，結構平穩，文辭平順。 | 大致能掌握題旨，略能發揮想像、抒發情感，結構尚稱完整，文辭平順。 |
| C | 敘寫不盡符合題旨，材料運用未盡允當，缺乏己見，結構鬆散，文辭欠通順。 | 敘寫不盡符合題旨，情意浮泛，結構鬆散，文辭欠通順。 |
| 0 | 空白卷，或文不對題，或僅抄錄題幹。 | 空白卷，或文不對題，或僅抄錄題幹。 |

How to read them as criteria (GSAT-Tutor operationalization):

| Dimension | 知性 cue words (A → B → C) | 情意 cue words (A → B → C) |
|---|---|---|
| 題旨 (task fulfilment) | 精確掌握 → 大致掌握 → 不盡符合 | 精確掌握 → 大致掌握 → 不盡符合 |
| 內容 (content) | 善用材料拓展發揮、思考深刻、論述明確 → 取用相關材料、內容平實 → 材料未盡允當、缺乏己見 | 發揮想像、構思巧妙、體悟深刻 → 略能發揮想像、抒發情感 → 情意浮泛 |
| 結構 (structure) | 嚴謹 → 平穩 → 鬆散 | 完整 → 尚稱完整 → 鬆散 |
| 文辭 (language) | 暢達 → 平順 → 欠通順 | 情辭動人 → 平順 → 欠通順 |

**題旨 dominates.** Each year's rubric writes the task's required components into every tier: e.g. 115 情意 asks for 原因＋換位思考＋回應; 111 知性 asks for 意義＋生理與情感需求. An essay with fine language that misses a required component cannot reach the top 等. One that addresses only part of the task usually lands in B.

### 1.4 Typical task-specific tier wording (115, verbatim)

第一大題 問題（二） 21分:
| 作答情形 | 級 | 分數 |
|---|---|---|
| 能適切舉出選擇逃避或積極承擔的事例，並清楚表達自己的看法與省思，結構嚴謹且具說服力，層次井然，文辭暢達。 | A+ | 21–19 |
| 能具體舉出…事例，並表達自己的看法與省思，結構允當，條理分明，文辭流暢。 | A | 18–15 |
| 能舉出…事例，並表達自己的看法與省思，結構合宜，文辭通順。 | B+ | 14–12 |
| 能大致舉出…事例，並表達自己的看法與省思，論述平平，文辭尚稱通順。 | B | 11–8 |
| 未能舉例，或舉例不當，內容不切情理，結構鬆散，文辭欠通順。 | C+ | 7–5 |
| 無法掌握題旨，敘寫雜亂，文辭不通。 | C | 4–1 |
| 空白卷、文不對題，或僅抄錄題幹。 | 0 | 0 |

第二大題 25分:
| 作答情形 | 級 | 分數 |
|---|---|---|
| 能具體陳述與對象產生隔閡的原因；能換位思考，嘗試溝通，並傳達自己的回應。結構嚴謹，文辭暢達。 | A+ | 25–22 |
| 能明確陳述…；能換位思考，嘗試溝通，並傳達自己的回應。結構完整，文辭流暢。 | A | 21–18 |
| 能大致描述…；能大致換位思考，嘗試溝通，並傳達自己的回應。結構適當，文辭通順。 | B+ | 17–14 |
| 能簡略描述…；能簡略換位思考…唯想法較為粗淺，或僅泛論。結構尚可，文辭平順。 | B | 13–10 |
| 稍能觸及與對象產生隔閡的原因，然內容空洞，結構鬆散，文辭欠通順。 | C+ | 9–6 |
| 敘寫雜亂，文句不通。 | C | 5–1 |
| 空白卷、文不對題，或僅抄錄題幹、題目。 | 0 | 0 |

Pattern: the tier verbs grade **how well each required component is handled**: 適切／具體 → 明確／清楚 → 能 → 大致 → 簡略／略能 → 稍能觸及／未能. Then come structure (嚴謹 → 完整／允當 → 合宜／適當 → 尚可 → 鬆散) and language (暢達／洗練 → 流暢 → 通順 → 平順／尚稱通順 → 欠通順 → 不通).

問題（一） 4分 (115, verbatim): A 4–3 「能確切說明女主角拒吃豬改吃魚的理由，內容完整，表達清晰。」; B 2 「能大致說明…理由，內容不夠完整。」; C 1 「解讀錯誤，敘述混亂。」; 0 「空白卷、文不對題，或僅抄錄題幹。」

## 2. Deductions and caps

**Standing deductions (every 111–115 rubric):**
- 第一大題: 「審視字數是否符合要求，錯別字是否過多，另斟酌扣分」.
- 第二大題: 「視標點符號之使用與錯別字之多寡，斟酌扣分」.
- Since 113: 「未遵守作答區之規定，從第二大題作答區開始寫作第一大題者，扣1分」, and likewise for the 第二大題.
- 限用中文: 「違者該作答部分不予評閱計分，惟專有名詞或試題有特殊要求者不在此限」.

**特殊評分原則 caps seen in 考試說明／參考試卷 rubrics** (apply them when the task has the same feature):

| Situation | Cap / deduction |
|---|---|
| 另立題目，但能扣緊題旨 (when a title is given) | 至多 B+ (14 of 21; 12 of 18) |
| 未訂定題目 (when 自訂題目 is required) | 至多 B+ (17 of 25), or 酌扣 2 分 when the task says to use the chosen object as the title |
| 未明確表達贊成或反對立場 (position task) | 至多 B+ (14 of 21) |
| 文未終篇，或一段成文 | 至多 B+ |
| 缺乏題幹所要求的要素 (e.g. 角色、對白、情節) | 至多 B+ (17 of 25) |
| Only one of two required parts answered (e.g. 只寫一方的原因) | 至多 B+ / B |
| 問題（一） missing the key concept (e.g. 未提及移除的是「網頁連結」) | 至多 B (2 of 4) |
| 超過行數／字數 | 酌扣 1 分 (e.g. 「文長超過 8 行者，酌扣 1 分」) |
| 未在作答區範圍內作答 | 酌扣 1 分 |

**0分**: 空白卷、文不對題、僅抄錄題幹（題目）.

Size of 錯別字／標點 deductions: officially just 「斟酌扣分」, with no fixed rate. GSAT-Tutor convention: fold them into the choice of score within the 級 (per the 115 statement in §1.1). Take a separate 1 point off only when errors are frequent or impede reading, and say this is an estimate.

## 3. Writing a 評分原則 for a generated task

Write it in 繁體中文, official table style. Name the task's required components in every tier.

```
第一大題 問題（二）（占 21 分）
作答情形｜等第｜級分｜分數
能適切……（要求一）並……（要求二），結構嚴謹，層次井然，文辭暢達。｜A｜A+｜21-19
能具體……並……，結構允當，條理分明，文辭流暢。｜A｜A｜18-15
能……並……，結構合宜，文辭通順。｜B｜B+｜14-12
能大致……並……，論述平平，文辭尚稱通順。｜B｜B｜11-8
未能……或……不當，內容不切情理，結構鬆散，文辭欠通順。｜C｜C+｜7-5
無法掌握題旨，敘寫雜亂，文辭不通。｜C｜C｜4-1
空白卷、文不對題，或僅抄錄題幹。｜0｜0｜0
另：審視字數是否符合要求，錯別字是否過多，斟酌扣分；未遵守作答區之規定者，扣1分。
※特殊評分原則：1. ……至多 B+（14 分）。
```

For 問題（一） (4分), also give a 參考答案要點: list the 2–3 elements a full answer must contain, in the material's wording. Then:
A 4–3 「能確切說明……，內容完整，表達清晰」; B 2 「能大致說明……，內容不夠完整」; C 1 「解讀錯誤，敘述混亂」; 0.

Label generated rubrics 「GSAT-Tutor 評分原則（依大考中心格式擬定）」.

## 4. Grading procedure (a student's essay)

1. **Get the task.** For a past task, open the prompt and 評分原則 pages (`question-index.md`). For a new task, write the rubric first (§3). If the student gives only the essay, ask for the prompt; if it's missing, infer the likely task and say so.
2. **Check hard constraints**: correct 大題 and title; required components present; 字數／行數 within limits (count Chinese characters, and estimate lines at 22 格 per line); Chinese only; finished essay.
3. **Decide 等 (A/B/C)** from 題旨 and content against the 表現描述 (§1.3) and the task tiers. Then decide **原級 or ＋級**, then the **分數** inside the band, adjusted for 錯別字, 標點 and polish.
4. **Apply caps and deductions** (§2) after the band decision, and name each one.
5. **Calibrate.** Real graders average two independent reads, and most essays sit in B to B+. Don't drift upward. A+ needs the task done fully *and* insight, structure and language that stand out. When unsure between two 級, give the lower and say what would lift it.

### Feedback output template
```
【等級與分數】B+（15／25）（GSAT-Tutor 依 115 學年度國寫第二大題評分原則估計）
【題旨檢核】要求一 ✔／要求二 △（只泛論，未具體）／要求三 ✘
【表現描述對照】題旨：大致掌握｜內容：……｜結構：……｜文辭：……
【扣分／上限】錯別字 3 處（列出）；無作答區問題；未觸發特殊評分原則
【亮點】引用學生原句說明
【升級關鍵】要從 B+ 到 A，最重要的 1–2 件事（具體到段落與句子）
【示範改寫】改寫學生的一段（同內容，示範 A 級的具體化／層次／收束）
```

Quote the student's own sentences as evidence. Rewrite at most one paragraph as a model, so the essay stays the student's own.

## 5. Weakness diagnosis

| Type | Signal | Fix |
|---|---|---|
| 審題 (task reading) | Missing a required component; answering a neighbouring question; wrong 大題 area | Underline every verb in the prompt (說明、分析、舉例、表明立場、換位思考…), checklist before writing |
| 問題（一） 擷取 | Partial elements; copied sentences without integration; over the limit | "Find all elements → paraphrase → count" drill, ≤80字 |
| 論證 (知性 argument) | Claims without examples; one-sided where two sides are asked; no own view (缺乏己見) | 立場句 → 2 concrete 事例 → 分析 → 回應反方 → 結論 frame |
| 具體化 (情意 concreteness) | 情意浮泛: generic feelings, no scene, no sensory detail | Scene-building drill: 時間／地點／人物／動作／感官／對話 |
| 體悟 (insight) | Ends with a cliché or moral; metaphor in the title not developed | Practise "literal → personal → general" transfer (縫隙, 52赫茲) |
| 結構 (structure) | No paragraphing, imbalance, abrupt ending (文未終篇) | 4–5 paragraph plan with time budget |
| 文辭 (language) | 錯別字, 標點, run-ons, colloquialisms | Personal 錯別字 list; read-aloud revision |

Map each weakness to the 測驗目標 (`scope.md` §2): 知性1 解讀分析, 知性2 思辨見解, 知性3 文辭組織; 情意1 經驗與聯想, 情意2 真誠抒發, 情意3 文辭組織.
