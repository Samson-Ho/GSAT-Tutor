## 111–115 學測國寫

### 111 (閱卷召集人 林啟屏)
- **第一大題（知性）**: 不老騎士 documentary vs 「樂齡卡打車」 activity.
  - 問題（一） 4分, 80字/4行: 二者活動內容的關鍵差異與用意. Rubric: A 4–3 確切說明關鍵差異與用意; B 2 僅略述差異或用意; C 1 略涉題旨但無法分辨.
  - 問題（二） 21分, 400字/19行: 以「樂齡出遊」為題，說明意義，並思考如何照顧長者生理與情感需求. A+ requires 適切說明意義＋具體考量生理與情感需求, 結構嚴謹，條理分明，文辭精練; B+ needs only 生理**或**情感需求.
- **第二大題（情意）** 25分: 〈我們的課本〉 poem + 費曼 → 以「當我打開課本」為題，敘述任一學科課本對你的意義，書寫探索課本內容、知識的經驗與體會. A+ 感受深刻，結構嚴謹，表達生動，文辭優美; C+ 未能敘述意義或探索經驗.
- Pages: p2, p3; 評分原則 p4–5.

### 112
- **第一大題（知性）**: 福爾摩斯 and 華生 dialogue.
  - 問題（一） 4分: 福爾摩斯認為華生犯了哪兩個「錯誤」.
  - 問題（二） 21分: 分析二人生活態度的差異，並說明你比較傾向哪一種.
- **第二大題（情意）** 25分: 蔣勳 prose on childhood smell → 以「花草樹木的氣味記憶」為題，書寫熟悉的花草樹木的氣味，及其所召喚的記憶和感受.
- Pages: p2, p3; 評分原則 p4–5.

### 113
- **第一大題（知性）**: 甲乙二文 on 標籤.
  - 問題（一） 4分: 「標籤」概念使用於人身上的正面與負面作用.
  - 問題（二） 21分: 舉例說明你對標籤現象的看法.
- **第二大題（情意）** 25分: forest-gap science text → 森林為何需要縫隙？人生是否也需要縫隙？以「縫隙的聯想」為題，結合生活經驗或見聞，書寫感思與體悟.
- First year with the stated rule 「從第二大題作答區開始寫作第一大題者，扣1分」 (and vice versa).
- Pages: p2, p3; 評分原則 p4–5.

### 114 (閱卷召集人 陳昌明)
- **第一大題（知性）**: 擬社會互動 (parasocial interaction) text.
  - 問題（一） 4分: 粉絲與公眾人物「擬社會互動」的特徵.
  - 問題（二） 21分: 就你的觀察，闡述擬社會互動的正、負面影響.
- **第二大題（情意）** 25分: 52赫茲鯨魚 → 以「關於52赫茲，我想說的是……」為題，抒發想像. Rubric: A+ 能具體書寫自己獨特的52赫茲故事或事理，結構嚴謹，文辭洗練，情感雋永; A 清楚書寫…結構完整，文辭暢達，情感深刻; B+ 書寫…內容平實，唯情感合宜，結構清楚，文辭通順; B 略能書寫…內容較欠深刻，結構尚可，文辭平順; C+ 敘寫浮泛，文辭欠通順; C 敘寫雜亂，文句不通.
- Pages: p2, p3; 評分原則 p4–6.

### 115 (閱卷召集人 陳昌明)
- **第一大題（知性）**: 《愛的迫降》 scene (the heroine refuses to eat the piglet travelling with them, but accepts fish) + Levinas's 「臉」 (黃宗慧、黃宗潔《就算牠沒有臉》).
  - 問題（一） 4分, 80字/4行: 女主角何以拒吃同行小豬，卻可接受吃從河裡捕來的魚？Rubric: A 4–3 確切說明理由，內容完整，表達清晰; B 2 大致說明，內容不夠完整; C 1 解讀錯誤，敘述混亂.
  - 問題（二） 21分, 400字/19行: 舉出生活見聞中選擇逃避或積極承擔的事例，就如何做出選擇，表達看法與省思. Rubric: A+ 21–19 適切舉例並清楚表達看法與省思，結構嚴謹且具說服力，層次井然，文辭暢達; A 18–15 具體舉例…結構允當，條理分明，文辭流暢; B+ 14–12 能舉例…結構合宜，文辭通順; B 11–8 大致舉例…論述平平; C+ 7–5 未能舉例或舉例不當，內容不切情理; C 4–1 無法掌握題旨.
- **第二大題（情意）** 25分: 幾米 圖文 on parent–child 隔閡 → 以「隔在我們之間的種種」為題，陳述與對象產生隔閡的原因，試著換位思考，並傳達自己的回應. Rubric: A+ 具體陳述原因；能換位思考，嘗試溝通，並傳達回應；結構嚴謹，文辭暢達 … B 簡略描述…想法較為粗淺，或僅泛論 … C+ 稍能觸及原因，然內容空洞.
- Pages: p2, p3–4; 評分原則 p5–7.
