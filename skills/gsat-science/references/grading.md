# 自然 — Grading 非選擇題, Writing 評分原則, Diagnosing Weaknesses

## 1. Official grading principles (from the 非選擇題評分原則 preambles)

> 在評分原則與給分方式上，會因試題要求的不同有所差異，重點為學生是否能夠清楚表達，故答題時應將解題過程說明清楚。解題的方式有很多種，但學生用以解題的觀點必須符合題目所設定的情境。（109試辦、110試辦、111）

> 關於作答文句中錯別字的評閱原則，各科如下：物理科、化學科、生物科、地球科學科：錯別字不扣分（除重要關鍵詞或專有名詞外）。（109試辦）

Conventions that recur across the 109–115 rubrics:

| Rule | Where it shows up |
|---|---|
| **Points are itemized**: each 空格／小題／橫列 scored independently, with explicit point values (1 or 2 分 each) | All years |
| **計算題: 列式 and 答案 scored separately.** 「列式正確得1分，答案正確再得1分；列式正確，答案不正確只得1分；**只寫答案沒有計算過程，則不給分**」 | 112-60, 113-49, 113-51, 114-56, 115-46 |
| **同義詞皆給分**: e.g. 增加／加快／變大／上升; 砍伐／死亡／鋸下 | 110-54, 111-40, 113-56, 114-40 |
| **答非所問或未作答者不給分** | All years |
| **勾選 gates the reason**: in 勾選＋理由 items, the reason earns credit only if the 勾選 is correct | 114-38 (「須先正確勾選淡水養殖池，才能獲得判斷理由的分數」) |
| **Reasons must be complete**: partial reasoning earns partial credit (e.g. only one of two required elements) | 109-37, 113-38, 113-41, 114-38, 115-41 |
| **Graph reading tolerance**: values read from a figure are accepted within a range | 110-60 (55–80 g), 114-49 (E 45–55 mV, R 125–175 Ω) |
| **作圖 criteria**: axis names, **units**, suitable scale or intervals, points correctly plotted, trend line (smooth curve or segments), correct reading. Each criterion is worth 1 分 | 110-57, 110-60, 111-45, 114-38, 115-50 |
| **Equation writing**: correct species 1 分 + correct coefficients 1 分; coefficients as fractions or doubled earn only partial credit; wrong species → 0 | 111-57, 112-47, 114-54 |
| **Scientific terms must be right**: 錯別字 are tolerated except for key terms or proper nouns. Missing symbols (e.g. writing f instead of Δf) can cost the point | 111-54 (「少寫 Δ 或 f，得 0 分」) |
| **Must exclude alternatives where asked**: e.g. pedigree reasoning must rule out sex-linkage | 112-50 (「不能排除性聯遺傳…得0分」) |

## 3. Writing a 評分原則 for a generated item

Template (繁體中文, official style):
```
第 39 題（4 分）
一、滿分參考答案：
（a）……
（b）……
二、評分原則：
（a）（2分）
（一）列式正確得1分，答案正確再得1分。
（二）列式正確，答案不正確只得1分。
（三）只寫答案沒有計算過程，則不給分。
（b）（2分）
（一）正確寫出「……」等同義詞者，得2分。
（二）未能完整說明者（僅提及……），得部分分數1分。
（三）答非所問或未作答者不給分。
```
Guidelines:
- Itemize so the points add up to the stated total; each point corresponds to one checkable element.
- Name acceptable synonyms and the minimum complete reason; state what earns partial credit.
- For graph reading, give a tolerance range. For 作圖, list the criteria (axes, units, scale, points, line).
- For 勾選＋理由, say whether the reason is gated by a correct 勾選.

## 4. Grading procedure

1. Get the exact item, its points and the rubric (official for past items, from the PDF page; write one first for new items).
2. Score each rubric element independently and quote the student's words or work as evidence.
3. Apply §1 strictly: no credit for an answer without the required 計算過程; synonyms accepted; key terms must be correct; reasoning must fit the 情境 given in the question (an answer that's true in general but ignores the stem's setup doesn't earn the point).
4. If the student's answer needs a figure or graph you can't see (e.g. a hand-drawn plot), ask for a photo or a description, or grade conditionally and say what you assumed.

### Feedback output template
```
【得分】x／4 分（依 114 學年度自然第38題評分原則估計）
【逐項評分】
（a）……（得 1／1）— 你的作答：「……」
（b）勾選……（得 0／1）；理由……（得 0／2，因勾選錯誤，理由不計分）
【扣分關鍵】……
【滿分作答要點】條列必須出現的關鍵詞／步驟／圖的要素
【弱點對應】學習內容代碼＋測驗目標（見 §5）
```

## 5. Weakness diagnosis

| Type | Signal | Typical fix |
|---|---|---|
| 觀念缺口 | Wrong law or model applied; misconception (e.g. 電子繞核靠重力, 颱風眼為高氣壓) | 觀念講解 for that code + 3–5 targeted 選擇題 |
| 資料判讀 | Misread graph axes, units or trends; can't extract information from the passage | Practise 2a/2c items: first describe the figure in words, then answer |
| 探究能力 | Confuses 操縱／控制／應變變因; over-generalizes (過度推論); picks the wrong comparison groups | Practise 探究 items (109-40~42, 113-43, 111-56); use the "only one variable differs" rule |
| 表達 | Correct idea but incomplete reason; missing units or axis labels; missing key term | Write answers against rubrics; checklist: 結論＋依據＋關鍵詞 |
| 計算 | Wrong mole ratio, unit conversion or significant step; no 列式 | Always show 列式; carry units; estimate the order of magnitude |
| 跨科整合 | Can handle each discipline alone but not combined contexts | Practise cross-disciplinary 題組 (see `trends.md` §3) |

Map each lost point to a 學習內容 code (or 探究與實作 item) and a 測驗目標 (1a–5c).
