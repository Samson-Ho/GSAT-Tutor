# 國綜 — Scope (國文考科考試說明 111學年度起適用 · 國文（一）：國語文綜合能力測驗)

Source: `assets/papers/exam-guide-111.pdf`. That 考試說明 covers both 國綜 and 國寫; this skill uses the shared front matter (p5–6) and the 國綜 part (p7–30). Quotes in 「」 are verbatim.

## 1. Place in 學測國文

- 學測國文 = 國文（一）國語文綜合能力測驗（國綜，滿分100分，90分鐘）＋ 國文（二）國語文寫作能力測驗（國寫，滿分50分，90分鐘）.
- 「國文考科原始得分＝（國綜得分 × 0.5）＋國寫得分」, so each part counts 50%.
- Basis: 108 國語文課綱. 「學測國文將以國語文課綱普通型高級中等學校部定必修課程為依據，測驗考生的語文能力、文學與文化素養。」
- 題型 (p6): 「國綜包含選擇題型（單選題、多選題）、混合題型（兼含選擇題與非選擇題）」.

## 2. 測驗目標 (p9, verbatim codes)

**一、國語文知識的認知與應用**
- A1. 字形、字音、字義的辨識與應用
- A2. 語詞、成語意義的辨識與應用
- A3. 語法的辨識與應用
- A4. 表現手法、表述方式的辨識與應用
- A5. 具備重要文學作家、作品、體類、流派的知識
- A6. 具備重要學術思想、文化的知識

**二、文本的理解與探究**
- B1. 訊息的檢索與擷取
- B2. 文意的理解、比較、分析、統整
- B3. 內容的延伸與反思
- B4. 形式的推究與分析
- B5. 結合文學、文化知識的詮釋與鑑賞

These codes are the tagging system for every item: the official 試題解析 of the 參考試卷 and 110試辦 tag each item with 1–3 of them. Always tag generated items the same way.

## 3. 測驗內容 (p10, verbatim)

**一、取材範圍**: 「符合普通高中學生程度、對應國文教材內容的古今各類文本。」 Per the 參考試卷說明, this includes 「古今詩歌、散文、小說，以及應用文、學術論文、跨領域文本、圖表等，兼顧文言與白話」. Per Q2, 「文本」 includes 「記敘文本」「抒情文本」「說明文本」「議論文本」「應用文本」, plus 「圖表、圖形、圖解、表單等等」.

**二、命題重點**
- （一）字詞、語法知識：字形、字音、字義、六書基本原則、語詞意義與結構、詞性、句型等。
- （二）文學知識：作家、作品、體類、流派的基本知識。
- （三）文本涵義：1. 文句的邏輯與意義（包含深層意涵與象徵意義）。2. 段落篇章的主旨、結構、寓意、分析與評述。
- （四）寫作方式、手法：各類文本的寫作方式或表現技巧。
- （五）文化內涵：各類文本所反映的物質文化、社群文化、精神文化內涵。

**三、取材原則**
- （一）兼顧文言文與白話文: 文言文 share follows the 課綱 rule 「課數比率須符合 3 年平均 35%至 45%」. 「國綜文言文命題取材比率，參酌此原則。」
- （二）適度反映各家版本之選文內容:
  - A類 = 四至五家版本之共同選文; B類 = 二至三家; C類 = 一家.
  - 「C 類以不高於教材選文試題之 10%為原則；B 類以不高於教材選文試題之 40%為原則；A 類試題不受上述比率之限制。」
  - Worked example (Q7): if 教材選文 items total 30分, B類 ≤ 12分 and C類 ≤ 3分.
  - Q6: there is **no fixed share** for 教材選文 items. 「國綜試題取材涵蓋古典、現代各文類與跨領域文本，而不以教材選文為限」.

- Q5 (official range): 「混合題型中的非選擇題占國綜全卷 100 分中 20-28 分」. In 111–112 the 混合題 totalled 22 (18 非選 + 4 選擇). Since 113 it has been one large 題組 worth 24 (20 非選 + 2 單選).
- **選擇題計分** (作答注意事項): 單選 all-or-nothing. 多選: 「各題之選項獨立判定，所有選項均答對者，得該題全部的分數；答錯 k 個選項者，得該題 $\frac{n-2k}{n}$ 的分數；但得分低於零分或所有選項均未作答者，該題以零分計算。」 With n = 5 options and 4分 per item: 1 wrong → 2.4分, 2 wrong → 0.8分, 3+ wrong → 0.
- 多選 have 「至少有一個」 correct option and **do not state how many**. Answers in 111–115 range from 2 to 4 correct options.
- 混合題 選擇 items are marked 「（占2分，單選題）」. 非選 parts state points and a 作答字數 limit, e.g. 「（占 4分，作答字數：30字以內。）」.
- 作答: 「非選擇題請由左而右橫式書寫」, written in the marked area 「限在答題卷標示題號的作答區內作答」.

## 5. 混合題 non-choice: what it is (Q3–Q4, verbatim gist)

- Purpose: 「讓考生在判斷選擇題正確答案之餘，進一步在非選擇題中，用精簡的文字表述答案或說明理由，以顯露思考的過程」. It tests 「演繹、歸納、分析、統整、說明的核心能力」.
- Versus 國寫: 「混合題型所評量的能力仍是以閱讀理解能力為主，相較於以寫作能力為核心的國寫，答案相對較為明確、答題字數相對較少」. 「以簡單明瞭的方式，解釋說明文本的內容或形式」. It does not ask for personal opinion or polished prose.
- Typical demand: extract a phrase from the text, explain a concept or reason, identify a 寫作手法 and its effect, link two texts, or fill a table or diagram.

## 6. Out of scope

- 加深加廣選修 (Q8): 「語文表達與傳播應用」「各類文學選讀」「專題閱讀與研究」「國學常識」 are 「不納入考試範圍」. Knowledge that belongs only to these courses (e.g. 國學常識 detail beyond 必修 texts) must be supplied in the stem if used.
- 國寫 essays (三等六級): use the GSAT-Tutor 國寫 skill.
- 分科測驗 has no 國文 subject. 指考國文 materials are pre-108 and only loosely comparable.

## 7. Knowledge areas the papers actually draw on (GSAT-Tutor summary)

Built from the 考試說明 例題, the 參考試卷, the 110試辦 and 111–115 (`question-index.md`, `trends.md`). Treat it as a map of what to know, not an official syllabus:

- **字音 (A1)**: 形聲字 with the same component read differently (闥/撻, 篙/蒿, 舁/臾, 攲/旖, 枇/毗, 諳/喑); 多音字; words from textbook texts.
- **字形 (A1)**: high-frequency 錯別字 in idioms and set phrases (價格不菲, 人謀不臧, 不落窠臼, 倒屣相迎, 伶牙俐齒, 矯揉造作, 無遠弗屆, 人情世故, 以儆效尤).
- **字義 (A1/A3)**: 一字多義 across textbook sentences (復、及、既、善、竟、當、向、爾、敢、得、常、猶、負、率、冠、與、為、於、乃、竊); 古今字義.
- **成語 (A2)**: usage in context, especially misused idioms (擘肌分理, 愛屋及烏, 來者可追, 得隴望蜀, 不足為訓, 白雲蒼狗, 空谷足音, 始作俑者, 胸無城府, 腹笥甚廣, 箕山之志, 席不暇暖, 摩頂放踵, 吐哺握髮, 沆瀣一氣, 授人以柄, 不次拔擢, 秣馬厲兵, 曲突徙薪).
- **語法 (A3)**: tested through examples in the stem, not terminology: 副詞修飾動詞程度 (頗、甚、極、略); 「以」表目的; 「則」表假設結果; 量詞分類 (名量詞／動量詞／借用量詞); 詞性; 句型.
- **表現手法 (A4/B4)**: 譬喻、類比、映襯、細節描寫、視角與敘事觀點、對話插入、感官描寫、文句排序與銜接 (古文排序 113-5, 115-5).
- **文學知識 (A5)**: 文學史 periods and genres (小說流變, 宋詞合樂, 元雜劇曲白, 駢文平仄, 新月派), authors of 教材選文 (蘇軾, 杜牧, 袁宏道, 歸有光, 諸葛亮, 李白, 杜甫), 臺灣文學 (賴和, 張李德和, 鄭用錫, 洪繻).
- **學術思想與文化 (A6)**: 儒家 (論語、孟子、荀子), 道家, 應用文 (書信用語: 啟封詞、提稱語、結尾頌詞; 題辭; 親屬稱謂 such as 家岳父、姻兄 in 115-3), 民俗與物質文化 (籤詩, 女書, 硃砂, 肥皂, 檳榔).
- **教材選文 that recur in items**: 〈出師表〉〈赤壁賦〉〈鴻門宴〉〈燭之武退秦師〉〈師說〉〈晚遊六橋待月記〉〈項脊軒志〉〈虬髯客傳〉〈桃花源記〉〈諫逐客書〉〈勞山道士〉〈廉頗藺相如列傳〉〈勸和論〉《論語》《孟子》. Expect quotations from them as options in 字義、語法 and 表現手法 items.
