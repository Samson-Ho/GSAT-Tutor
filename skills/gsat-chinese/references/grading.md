# 國綜 — Grading 混合題 非選擇題, Writing 評分原則, Diagnosing Weaknesses

## 1. Official grading principles (verbatim, 111–115 評分原則 preamble)

> 國語文綜合能力測驗閱卷委員訂定評分標準時，會依據試題內容，參酌考生實際作答情形，列出各題之滿分答案、部分給分答案與不給分答案。考生作答內容若在關鍵字詞、專有名詞上出現錯別字，或錯別字影響答案的完整性與正確性，都將酌予扣分。由於考生答題類型繁多，實際評閱時的各種給分情形，在此無法一一羅列，以下謹提供滿分參考答案及評分原則供各界參考。

110試辦 (earlier, more lenient): 「考生作答內容若偶有錯別字，但不影響文意判讀，錯別字不扣分。」 Use the 111+ rule.

What this means operationally:

| Situation | Credit |
|---|---|
| Key idea of the 參考答案 present and complete (any wording) | 滿分 |
| Key idea partly right, or one required component missing | 部分給分 (2 of 4) |
| Answer copies the right area of the text but doesn't answer the question asked | 0, or partial at most |
| Wrong idea, irrelevant, or blank | 0 |
| 錯別字 in a key term or proper noun, or one that damages completeness | 酌予扣分 |
| Alternative answers listed with 「或：」 | All equally full-credit |

## 2. Rubric tiers used by 大考中心

**111–115 (every item uses one of these):**

| Type | Tiers (verbatim) |
|---|---|
| 2分 exact | 能正確寫出參考答案之文句 2分／未作答或答案完全錯誤 0分 |
| 4分 explanation | 能寫出參考答案大意，且敘述完整 4分／答案敘述部分錯誤或不完整 2分／未作答或答案完全錯誤 0分 |
| 2分 two-part | 能正確寫出參考答案之文句 2分／僅正確寫出其中一項 1分／未作答或答案完全錯誤 0分 (113-33(2) 大腦) |
| 4分 synthesis | 能歸納綜整寫出條件，並從文中引用正確文句 4分／答案敘述部分錯誤或不完整 2分／0分 (111-34(2)) |

**參考試卷 and 試辦 (legitimate richer models):**

| Type | Tiers |
|---|---|
| 6分 appreciation (卷一-31 李清照) | 能清楚說明景語中所蘊含的感情 6分／能寫出景與情的關係，但說明不完整，或部分錯誤 4分／僅摘出景語或情語，但內容空泛，或解釋模糊 2分／未作答或離題 0分 |
| 寫作手法 (卷一-29) | 能正確寫出參考答案 4分／答案欠精確，如誇飾、擬人等 2分／答案完全錯誤，如只敘述意義或只抄文句，沒談到「描寫手法」等 0分 |
| 勾選＋理由 (卷一-34) | 有勾選且與理由扣合 1分; 理由 能完整說明 4分／不完整或部分錯誤 2分／0分; 「僅勾選而未說明理由者不給分」. Either stance can score if 「言之成理」 |
| 分項 (卷二-33) | 每項獨立給分 2／1／0; 特殊評分原則: splitting one reference item into two earns only one item's credit |
| 1分 items (試辦-34, 38) | 能精確寫出…作為 1分／未作答、答案未精確或完全錯誤 0分 |

Patterns visible across these rubrics:
- **The answer is in the text.** Reference answers paraphrase the passage closely. Full marks come from finding the right part and stating it completely.
- **Two-part questions are graded as a whole.** For 「基於何種考量，因此採取什麼行動」, both parts are needed for 4. One part earns 2.
- **Concept application** needs the concept's own terms (框架, 提醒物, 自主／不由自主).
- **Short limits** (10–40字) mean no room for background. Lead with the answer.

## 4. Writing a 評分原則 for a generated item

```
第 33 題
一、滿分參考答案：
(1) ……
    或：……
(2) ……
    或：……
二、評分原則：
第 33 題 (1)
評分原則｜給分
能正確寫出參考答案之文句｜2分
未作答或答案完全錯誤｜0分
第 33 題 (2)
評分原則｜給分
能寫出參考答案大意，且敘述完整｜4分
答案敘述部分錯誤或不完整（如：只寫出……，未說明……）｜2分
未作答或答案完全錯誤｜0分
```
- List the accepted alternative wordings with 「或：」.
- For a 2-tier item, say what counts as 「部分錯誤或不完整」 (the official 參考試卷 rubric does: 「如只寫『花落在誰的臉上較多』」).
- Label it 「GSAT-Tutor 評分原則（依大考中心格式擬定）」.

## 5. Grading procedure (a student's answer)

1. Get the question, its points, and the rubric: the official one for past items (open the PDF), or one you write first for new items.
2. For each sub-item, compare with the 參考答案's **key idea**, not its wording. Check every required component. Check the 字數 limit: answers far over the limit are not what was asked, so note it, though no fixed official penalty exists.
3. Check 錯別字 in key terms or proper nouns and apply 「酌予扣分」. GSAT-Tutor convention: drop one tier if a key term is miswritten, and say this is an estimate.
4. Total and state: 「x／y 分（GSAT-Tutor 依 114 學年度國綜第35題評分原則估計）」.

For 選擇題 a student got wrong, explain why the key is right, why their option is wrong (with text evidence), and which 測驗目標 the miss reveals.

### Feedback output template
```
【得分】x／y 分（依……評分原則估計）
【逐小題】(1) 2／2 —「學生原句」— 命中關鍵：…… (2) 2／4 — 缺少：……
【滿分寫法】(1) …… (2) ……（標出必須出現的關鍵詞）
【錯別字】……
【弱點對應】測驗目標 B2／B5；錯誤類型：……
```

## 6. Weakness diagnosis

| Type | Signal | Fix |
|---|---|---|
| 基礎知識 (A1–A2) | Misses on 字音, 字形, 字義, 成語 | Spaced review lists from past items 1–2 and the 字義／成語 multi-selects; classify by 形聲 component |
| 語法與手法 (A3–A4) | Misses by-example grammar or technique items | Practise identifying the pattern in the stem example before reading options |
| 文學文化 (A5–A6) | 文學史, 思想, 應用文 slips | Tie facts to 教材選文 and authors; mini timelines |
| 擷取 (B1) | Wrong detail or wrong text (甲 vs 乙) | Annotate who-says-what in multi-text sets |
| 理解推論 (B2) | Overgeneralization, reversed causality, 無法判斷 vs 不符合 confusion | ①② drills: mark the exact supporting line or say "no line" |
| 延伸應用 (B3) | Misses application or real-life items | Restate the text's principle in one line, then test each option against it |
| 形式 (B4) | Misses structure, technique or 寫作策略 items | Name the move: 對比, 舉例, 引證, 先總後分, 視角 |
| 鑑賞 (B5) | Poetry and classical appreciation errors | 景→情 and 典故 practice with 必修 poems |
| 非選表達 | Partial credit on 4分 items | Answer all components, use the text's key words, keep within the limit |
