# 數A — Grading 非選擇題, Writing 評分原則, Diagnosing Weaknesses

## 1. Official grading principles (verbatim, 114/115 非選擇題評分原則 preamble)

> 數學A考科的非選擇題主要評量考生是否能夠清楚表達推理論證過程，答題時應清楚表達如何依據題設進行推論，並詳細說明解題過程，且得到正確答案，方可得到滿分。若能清楚表達如何依據正確題設進行推論，並詳細說明解題過程，但最後未求出正確答案，會依據解題概念的完整性，酌給部分分數。若未能依據正確題設進行推論，或未能詳細說明解題過程，則不予給分。例如沒有解題過程；或利用錯誤推論；或使用不符合題設的數據作答，均不給分。
>
> 數學科非選擇題的解法通常不只一種，在此提供多數考生可能採用的解法以供各界參考。

Earlier wording (110試辦／111): 「…若過程中列式正確，但計算錯誤，則酌給部分分數。如果只有答案對，但觀念錯誤，或過程不合理，則無法得到分數。」

What this means operationally:

| Situation | Credit |
|---|---|
| Correct reasoning, clearly expressed, correct answer | 滿分 |
| Correct reasoning from correct conditions, but arithmetic slip or unfinished | 部分給分, proportional to how complete the concept chain is |
| Answer only, no process | 0 |
| Correct answer reached by a wrong argument, or by data not given in the problem | 0 |
| Any valid method (not only the reference solutions) | Full credit if complete and correct |
| Claims not justified (e.g. "顯然", or asserting perpendicularity without reason) | That rubric point is not earned |

## 2. Rubric structure used by 大考中心

- Each 非選 part has 2–4 **independent scoring items** (評分原則 一、二、三… or 1. 2. 3. 4.), each tied to one essential step or result, e.g. 「正確寫出 $\vec{AP}$」「正確計算體積」.
- 114 and 115 state the tiers explicitly:
  - **滿分**：以下各項均須正確（列出各項）
  - **部分給分**：列出哪些部分正確可得部分分數（e.g. 「正確方法求得 $\vec{AP}$，但未能正確求得 $\vec{AB}$、$\vec{AD}$」）
  - **零分**：未作答或未符合部分給分原則。
- Points per item are not printed in the 數A rubrics (unlike 自然). When grading, distribute the part's points evenly across its items unless one item is clearly the main step. Say that this split is GSAT-Tutor's estimate.

Recurring requirements visible across these rubrics:
- **說明題 need the reason**, not just the conclusion (112-19 「理由須正確」; 113-19 must note that cos is decreasing on $[0,\frac\pi2]$).
- **Boundary and domain arguments** are explicit scoring items (113-20: the vertex c=−2 is outside the range, so the minimum is at the endpoint $c=2-2\sqrt3$).
- **Drawing tasks** (111-19) are graded on the region being correctly marked.
- **Multiple accepted forms**: e.g. polar coordinates $[\sqrt3,150°]$ or $[\sqrt3,\frac{5\pi}{6}]$; $64-32\sqrt3$ under a root or $4(\sqrt3-1)$.

## 3. Writing a 評分原則 for a generated item

Use this template, in 繁體中文, official style:

```
第 20 題（8 分）
一、滿分參考答案：
【解法一】……（完整、橫式、每步有依據）
【解法二】……（若有常見另解）
二、評分原則：
滿分：以下各項均須正確
1. 正確……（關鍵步驟一），且過程正確。
2. 正確……（關鍵步驟二），且過程正確。
3. ……
部分給分
1. 正確方法求得……，但未能……。
2. ……
零分
未作答或未符合部分給分原則。
（GSAT-Tutor 配分建議：1. 3分；2. 3分；3. 2分）
```

Guidelines:
- Tie each scoring item to a mathematically essential step: a setup, a key relation, a justification, a final value.
- If the item asks to 說明 or 證明, make "理由正確" its own scoring item.
- List the common alternative methods; any correct method earns full credit.
- State accepted equivalent answer forms.

## 4. Grading procedure (for a student's answer)

1. Get the exact question, its point value and the rubric (official for past questions; write one first for new items).
2. Read the student's work line by line. For each scoring item decide: earned / partially earned / not earned. Quote the student's line as evidence.
3. Apply the official principles in §1 strictly. In particular:
   - an answer with no process earns nothing;
   - a correct final number reached by an invalid argument earns nothing for that item;
   - a correct setup with an arithmetic slip earns partial credit under that item;
   - an error carried forward: if a later step is methodologically correct but uses a wrong earlier value, official 數A rubrics still require 「過程正確」 for each item. Treat it as partial credit at most, and say so.
4. Total the points and state the score as e.g. 「5／8 分（GSAT-Tutor 依官方評分原則估計）」.

## 5. Weakness diagnosis

Classify every lost point:

| Type | Signal | Typical fix |
|---|---|---|
| 觀念缺口 (concept gap) | Wrong method, wrong formula, wrong model | Re-learn the unit (觀念講解), then 2–3 targeted items |
| 推理／表達 (reasoning/expression) | Right idea, but missing justification or 說明 | Practice writing full-mark 非選 answers against rubrics |
| 條件與範圍 (conditions/domain) | Ignored the domain, an endpoint, a case, or an extraneous root | Checklist habit: domain, cases, endpoints, reject-and-say-why |
| 計算 (execution) | Arithmetic or sign errors with a correct setup | Slow-down and verification routines; estimate to sanity-check |
| 閱讀 (reading) | Misread the stem, the units or the question asked | Underline givens and the exact ask; restate the question |

Map each lost point to a 學習內容 code from `scope.md` and one 測驗目標 (概念性知識／程序性知識／閱讀與表達／連結能力／推理能力／解決問題).

2. …
